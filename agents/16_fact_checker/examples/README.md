# Example transcript

`sample_transcript.md` is a ~200-word self-authored speech containing
a deliberate mix of claim types so the fact-checker exercises every
verdict path when run against real web search:

- A verifiable-true claim (Eiffel Tower location).
- A verifiable-false but widely-believed claim (Great Wall visibility
  from the Moon).
- A subjective / opinion claim (should be dropped at extraction, not
  even sent to search).
- An unverifiable private-anecdote claim (no public referent).

All content self-authored, no real people, no real companies. Point
the CLI at any `.md`, `.txt`, audio file, YouTube URL, or a raw
string to fact-check your own content.
