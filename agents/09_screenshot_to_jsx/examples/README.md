# Sample screenshots

Two self-owned mock screenshots for the Gradio UI's sample-picker
widget and for local demo purposes.

- `landing_page.png` (1440x900): a generic marketing-style landing
  page mockup with a header bar, hero section, three-column feature
  grid, and a footer. Simple filled rectangles standing in for real
  content; no logos, brands, or real text.
- `dashboard.png` (1440x900): a generic admin-dashboard mockup with
  a left sidebar, top bar, four stat cards, a bar chart, a side
  panel, and a data table.

Both images were generated procedurally with PIL (see the block that
originally produced them in this repo's session history). They are
NOT screenshots of any real product or website -- no attribution or
license concerns.

If you want to demo the agent against a real screenshot, upload your
own via the Gradio UI's file picker instead of using these.
